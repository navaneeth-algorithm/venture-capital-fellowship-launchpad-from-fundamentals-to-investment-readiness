# Venture Capital Fellowship Launchpad: From Fundamentals to Investment Readiness

This roadmap is designed for aspiring VC fellows to build a robust understanding of venture capital, from foundational concepts and market analysis to financial modeling, due diligence, and deal structuring. The journey culminates in a comprehensive capstone project where you'll apply your knowledge to develop and present an investment thesis, preparing you for success in your VC fellowship.

## Structure
Each phase of this roadmap exists as a separate Git branch.
